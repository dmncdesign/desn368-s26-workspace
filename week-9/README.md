Project description
-i was doing a gamecube advertisement for motion2 (you can see my rough draft video linked in the page!), so i thought it'd be fun to experiment with the timely aesthetic more since I was doing it at the same time. Plus, I was looking at a lot of early 2000's websites and found some really cool designs I liked.

Which CSS transform you implemented
-i implemented a transform on the buttons, so when you hover them they float up (and also get a drop shadow)

Which CSS animation you implemented
-i implemented the animation of the page fading in when you open the page.

Which table content type you chose
-i chose to make a comparison chart of different products (in this case, their memory cards, since they're multiple types). i wasn't really sure what to do but found this to be a suitable solution since i was doing other accessories for the gamecube as well.

Challenges encountered and solutions
-i still am bad at trying to position images and buttons and making things scale... but i just kept playing around until things worked! especially with my decorations (as you can see with the gray divs that I used at the end of certain sections to add decoration) the other issue I encountered was while trying to make more background images.. if you look at my figma you can see the purple lines behind a few sections, i for the life of me could not get them to scale correctly no matter what i tried, so ultimately i decided to remove them (for now). maybe with more experience i can figure it out.

Key learnings
css animations!! how to use flexbox and grid better.. and when it's better to use one or the other. i spent way too long making this website...
